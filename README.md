# Site do PPGAU UNIVAG

Site do Programa de Pós-Graduação Stricto Sensu em Arquitetura e Urbanismo do UNIVAG Centro Universitário.

- As páginas na raiz são geradas. Não edite à mão: altere `gerador/build.js` e gere de novo (instruções em `gerador/LEIA-ME.md`).
- `dados/` é uma cópia do portal [PPGAU em dados](https://territoriocidadearquitetura-design.github.io/PPGAU-DADOS/).
- Os painéis restritos (`restrito-prof.bin`, `restrito-coord.bin`) são cifrados. Sem a senha, o conteúdo deles não pode ser lido.

Organização e diagramação do site: Profa. Dra. Sandra Medina Benini (PPGAU/UNIVAG, 2026).
